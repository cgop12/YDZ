## 📋 版本策略

### 版本号规则

```
主版本.次版本.修订版本

示例: v1.2.3
- 主版本 (1): 不兼容的重大 API 变更
- 次版本 (2): 向下兼容的新功能
- 修订版本 (3): 向下兼容的缺陷修复
```

### 发布周期

| 版本类型 | 周期 | 说明 |
|---------|------|------|
| 修订版本 | 2-4 周 | 紧急缺陷修复，随时发布 |
| 次版本 | 3-6 月 | 计划内功能迭代 |
| 主版本 | 6-12 月 | 重大架构变更 |
